Обработка данных в демонстрационном проекте

«Форма Дома» — учебный демонстрационный проект для портфолио. Сайт не является действующим интернет-магазином или сервисом оформления заказов.

Назначение формы

Форма предназначена исключительно для демонстрации работы калькулятора, проверки данных и передачи тестовых заявок. Используйте только вымышленные сведения. Не вводите реальные персональные данные, контактные номера, адреса и конфиденциальную информацию.

Какие сведения передаются

При отправке демонстрационной формы передаются заранее заданные вымышленные имя, телефон и комментарий, а также выбранная категория или модель мебели и параметры расчёта. Поля контактных данных доступны только для просмотра. Также используются технические идентификаторы попытки отправки и средства защиты формы.

Как работает передача данных

Сайт размещён на GitHub Pages. Запросы формы проходят через Yandex API Gateway и закрытую функцию Yandex Cloud, затем передаются в Cloudflare Worker. Для защиты от автоматических отправок применяется Cloudflare Turnstile. Cloudflare D1 используется для хранения технических записей и идентификаторов попыток. Тестовые заявки передаются в настроенный Telegram-чат через Telegram Bot API.

Используемые сторонние сервисы могут обрабатывать технические сведения о соединении и запросах. Обработка может происходить за пределами Российской Федерации.

Защита от повторной отправки

Для защиты формы используются временный CSRF-токен, технические идентификаторы, локальное хранилище браузера и серверный реестр попыток отправки. Эти механизмы предназначены для снижения риска повторной доставки одной заявки.

Хранение сведений

Технические записи могут сохраняться в базе данных, а сообщения — в настроенном Telegram-чате. Окончательные сроки хранения, порядок удаления и обращения по вопросам обработки данных для действующего коммерческого сайта не утверждены.

Ограничения демонстрационного проекта

Проект не предназначен для сбора персональных данных реальных клиентов. До начала коммерческого использования необходимо определить оператора персональных данных, правовые основания обработки, сроки хранения, порядок обращения пользователей и требования к передаче данных сторонним сервисам.
